ЗАЯВКИ В TELEGRAM — ПІДКЛЮЧЕННЯ
===============================
Пошта продовжує працювати як раніше. Telegram додається ПАРАЛЕЛЬНО:
одна заявка → два канали одночасно. Якщо один не спрацював, другий
усе одно доставить.

Є два способи. Обирайте ОДИН.


┌───────────────────────────────────────────────────────────┐
│ СПОСІБ А — ЧЕРЕЗ GOOGLE (рекомендований)                  │
│ 20 хвилин. Токен бота захований, плюс архів у таблиці.    │
└───────────────────────────────────────────────────────────┘

КРОК 1. Створити бота
---------------------
1. У Telegram знайдіть @BotFather
2. Надішліть команду:  /newbot
3. Введіть назву (напр. GlassGuard Заявки)
4. Введіть логін — має закінчуватись на bot (напр. glassguard_leads_bot)
5. BotFather пришле ТОКЕН — довгий рядок виду
   8012345678:AAHdq...   Збережіть його, він знадобиться.

КРОК 2. Дізнатись ID чату
-------------------------
Тут беруть участь ДВА РІЗНИХ БОТИ, і їх легко переплутати:
  @userinfobot     — чужий службовий бот. Він просто каже ваш номер.
  ваш власний бот  — той, якого ви створили в кроці 1. Саме він
                     надсилатиме заявки.

2.1. Дізнатись свій номер
  1. У пошуку Telegram введіть @userinfobot і відкрийте його
  2. Натисніть синю кнопку "Запустити" (Start) унизу екрана
  3. Він одразу відповість чимось на кшталт:
        Id: 123456789
        First: Олександр
  4. Збережіть це число — це і є ваш CHAT_ID

2.2. Дозволити СВОЄМУ боту писати вам  ← найчастіша причина збою
  Telegram захищає людей від спаму: бот НЕ МОЖЕ написати першим
  тому, хто сам із ним не почав розмову. Поки ви не натиснули Start
  у свого бота, заявки не дійдуть — і що гірше, ніде не буде видно
  помилки, просто тиша.

  Як це зробити:
  1. Знайдіть свого бота. Два способи:
     • у повідомленні від BotFather є посилання виду
       t.me/glassguard_leads_bot — просто натисніть на нього;
     • або введіть у пошук Telegram його логін із кроку 1
       (той, що закінчується на bot).
  2. Відкрийте діалог із ним.
  3. Унизу екрана буде широка синя кнопка "Запустити" (Start) —
     натисніть її.
     Якщо кнопки немає (ви вже відкривали цей діалог раніше) —
     просто надішліть текстом:  /start

  4. Бот НІЧОГО НЕ ВІДПОВІСТЬ. Так і має бути.
     Це не помилка: ваш бот поки що вміє тільки надсилати заявки,
     відповідати людям його ніхто не вчив. Єдине, що мало статись, —
     діалог тепер існує, і Telegram дозволив боту вам писати.

  5. Перевірити, що дозвіл спрацював, можна буде в кроці 4:
     запустите функцію testSend — якщо тестова заявка прийшла,
     значить усе гаразд.

  ЩО НЕ МОЖНА РОБИТИ ПОТІМ:
  • не блокуйте цього бота;
  • не видаляйте з ним чат (Telegram вважає це відмовою від бота).
  У будь-якому з цих випадків заявки перестануть приходити. Лікується
  тим самим: відкрити бота й натиснути Start ще раз.

2.3. Варіант для спільної групи (якщо схочете отримувати вдвох)
  1. Створіть групу, додайте туди свого бота як учасника
  2. Додайте в групу @getidsbot — він покаже Id групи
  3. Id групи починається з мінуса, напр. -1001234567890
  4. Потім @getidsbot можна видалити
  У групі кнопку Start натискати не треба: досить того, що бота
  додали учасником — цього вже достатньо, щоб він міг туди писати.

КРОК 3. Створити приймач заявок
-------------------------------
1. Відкрийте https://script.google.com
2. Натисніть "Новий проєкт"
3. Видаліть увесь текст, що там є
4. Відкрийте файл apps-script.gs (лежить поруч із цим файлом),
   скопіюйте ВЕСЬ його вміст і вставте у вікно Google
5. Угорі коду замініть:
      СЮДИ_ТОКЕН_БОТА  → токен із кроку 1
      СЮДИ_ID_ЧАТУ     → id із кроку 2
6. Натисніть значок дискети (зберегти)

КРОК 4. Перевірити, що бот пише
-------------------------------
1. У випадному списку зверху виберіть функцію  testSend
2. Натисніть "Виконати"
3. Google попросить дозвіл — "Переглянути дозволи" → оберіть свій
   акаунт → "Додатково" → "Перейти до проєкту (небезпечно)" → "Дозволити"
   (це стандартне попередження Google для власних скриптів, воно нормальне)
4. У Telegram має прийти тестова заявка

КРОК 5. Опублікувати
--------------------
1. Кнопка "Розгорнути" (Deploy) → "Новий розгортання"
2. Тип: натисніть шестерню → "Вебдодаток"
3. Виконувати від імені: Я
4. Хто має доступ: ВСІ  ← це обов'язково, інакше сайт не достукається
5. "Розгорнути"
6. Скопіюйте "URL вебдодатка" — виглядає так:
   https://script.google.com/macros/s/AKfycb..../exec

КРОК 6. Прописати на сайті
--------------------------
1. Відкрийте assets/site.js
2. Знайдіть рядок:   const LEAD_WEBHOOK_URL = "";
3. Вставте адресу в лапки:
   const LEAD_WEBHOOK_URL = "https://script.google.com/macros/s/AKfycb.../exec";
4. Збережіть, залийте файл на хостинг
5. Заповніть форму на сайті — заявка має прийти і на пошту, і в Telegram

АРХІВ ЗАЯВОК У ТАБЛИЦІ (необов'язково, 2 хвилини)
-------------------------------------------------
1. Створіть порожню Google Таблицю
2. З її адреси скопіюйте id — це те, що між /d/ і /edit:
   docs.google.com/spreadsheets/d/  1AbCdEf...XyZ  /edit
3. У коді скрипта вставте його в рядок SHEET_ID
4. Збережіть і зробіть "Розгорнути" → "Керувати розгортаннями" →
   олівець → Версія: "Нова версія" → "Розгорнути"

Тепер кожна заявка ще й лягає рядком у таблицю. Зручно рахувати,
скільки заявок за місяць і з якої сторінки вони приходять.


┌───────────────────────────────────────────────────────────┐
│ СПОСІБ Б — НАПРЯМУ (швидко, але з недоліком)              │
│ 5 хвилин. Токен бота буде видно всім.                     │
└───────────────────────────────────────────────────────────┘

Зробіть кроки 1 і 2 зі способу А, а далі просто впишіть токен та id
у файл assets/site.js:

   const TELEGRAM_BOT_TOKEN = "8012345678:AAHdq...";
   const TELEGRAM_CHAT_ID   = "123456789";

І все — працює одразу.

У ЧОМУ НЕДОЛІК. Файл site.js лежить на сайті у відкритому вигляді:
будь-хто може натиснути "Переглянути код сторінки" й побачити токен.
Маючи токен, сторонній може надсилати повідомлення у ваш чат від імені
бота — тобто засмітити його спамом. Доступу до вашого акаунта, до
пошти чи до чужих чатів це не дає, і токен у будь-який момент
відкликається в @BotFather командою /revoke — після цього старий
перестає працювати.

Для тесту на GitHub Pages спосіб Б цілком прийнятний. Перед справжнім
запуском із доменом краще перейти на спосіб А.


ЯКЩО НЕ ПРАЦЮЄ
--------------
• Прийшло на пошту, але не в Telegram
  → перевірте крок 4 (testSend). Якщо тест не проходить — справа
    в токені або id чату, а не в сайті.

• testSend спрацював, а з сайту не йде
  → майже завжди причина в кроці 5, пункт 4: доступ має бути "ВСІ".
    Змініть і обов'язково створіть НОВЕ розгортання.

• Змінили код скрипта, а нічого не змінилось
  → Google запам'ятовує стару версію. Потрібно "Керувати
    розгортаннями" → олівець → Версія: "Нова версія" → "Розгорнути".

• Бот мовчить в особистих повідомленнях
  → ви не натиснули Start у свого бота. Telegram забороняє ботам
    писати першими.
